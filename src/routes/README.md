# Routes

TanStack Start uses file-based routing in this directory. `__root.tsx` is the root layout and must preserve `<Outlet />`. Do not introduce a second Next.js or Remix routing tree.

| File                | URL or purpose                                              |
| ------------------- | ----------------------------------------------------------- |
| `index.tsx`         | `/`                                                         |
| `chat.tsx`          | `/chat`                                                     |
| `files.tsx`         | `/files`                                                    |
| `setup.profile.tsx` | `/setup/profile`                                            |
| `__root.tsx`        | Initialization, providers, error boundary, and route outlet |

`src/routeTree.gen.ts` is generated by the routing plugin; do not edit it manually. Native calls belong behind service interfaces and the preload bridge. A route rendering successfully does not establish that every action on that route has been tested. See [development and testing](../../docs/DEVELOPMENT.md).
